## Project Overview

This repository presents my practical portfolio for MIT 8103 Advanced Database Systems.

Using the CareBridge hospital case study, the project demonstrates practical applications of database design, modelling, implementation, query processing and optimisation, transaction management, NoSQL data modelling, and distributed database systems.

## Portfolio Structure

The portfolio contains five practical activities:

1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Database Exercise

Each portfolio folder contains relevant documentation, implementation files and supporting evidence of the work completed.
