# MIT8103-CareBridge-Database-Portfolio
Advanced Database Systems

Programme: Master of Information Technology
Institution: Miva Open University
Academic Session: 2026/2027

##Project Overview

This repository contains my practical portfolio for MIT 8103 Advanced Database Systems.

The project uses the CareBridge hospital case study to demonstrate practical skills in database design, modelling, implementation, query processing, optimisation, transaction management, advanced data models, and distributed database systems.

Portfolio Structure

The repository will document the five practical portfolio activities:

Database Design and Modelling

Query Processing and Optimisation

Transactions and Concurrency

NoSQL and Advanced Data Models

Distributed and Cloud Database Exercise

Tools and Technologies

Tools and technologies will be documented as they are applied throughout the project.

Academic Integrity

This is an individual academic portfolio. AI tools may be used as learning and development assistants, with their contributions reviewed, understood, tested, and appropriately acknowledged.
